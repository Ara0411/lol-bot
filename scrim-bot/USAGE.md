# 🎮 내전봇 사용법

---

## ✅ 처음에 딱 한 번만: 디스코드 별명 바꾸기

내 별명을 이렇게 만들어주세요:

```
롤닉네임#태그/티어/라인
```

**예시**
- `완댕이#명명펀치/M350/MID.TOP`
- `정도#kr1/D2/JG`
- `석이#No1/G3/SUP`

**바꾸는 법**
서버에서 **본인 이름 우클릭 → "별명 변경"** → 위 형식대로 입력 → 저장

> 별명 형식이 안 맞으면 참가가 안 되니까 꼭 맞춰주세요.

---

## 🎯 티어 어떻게 쓰는데?

| 티어 | 이렇게 쓰면 됨 |
|------|---------------|
| 챌린저 | `C` 또는 `C500` (LP 같이 써도 OK) |
| 그랜드마스터 | `GM` 또는 `GM100` |
| 마스터 | `M` 또는 `M350` |
| 다이아 1~4 | `D1`, `D2`, `D3`, `D4` |
| 에메랄드 1~4 | `E1`, `E2`, `E3`, `E4` |
| 플레티넘 1~4 | `P1`, `P2`, `P3`, `P4` |
| 골드 1~4 | `G1`, `G2`, `G3`, `G4` |
| 실버 1~4 | `S1`, `S2`, `S3`, `S4` |
| 브론즈 1~4 | `B1`, `B2`, `B3`, `B4` |
| 아이언 1~4 | `I1`, `I2`, `I3`, `I4` |

> `다이아1`, `에메2` 처럼 한글로 써도 됩니다.

---

## 🎯 라인은 어떻게 쓰는데?

| 라인 | 이렇게 쓰면 됨 |
|------|---------------|
| 탑 | `TOP` 또는 `탑` |
| 정글 | `JG` 또는 `정글` |
| 미드 | `MID` 또는 `미드` |
| 원딜 | `AD` 또는 `원딜` |
| 서폿 | `SUP` 또는 `서폿` |

**여러 라인은 점(.) 또는 콤마(,)로 구분**
- `MID.TOP`
- `미드, 원딜`
- `JG.MID.SUP`

---

## 🚀 내전 모집 시작하기

채널에 이거 입력하세요:

```
/내전모집
```

→ 그냥 엔터 = **10명 모집**
→ 정원 옵션 클릭 = **10명 또는 20명** 선택

---

## 🟢 참가 / 🔴 취소

모집 메시지에 버튼 3개가 보일 거예요:

- **🟢 참가하기** — 클릭하면 본인 들어감
- **🔴 취소하기** — 클릭하면 본인 빠짐
- **📋 정리** — 정원 다 차면 활성화됨 (시전자만 누를 수 있음)

---

## 🕐 정원이 다 찼다면?

- 11번째부터는 자동으로 **대기자**로 들어가요
- 누가 빠지면 → 대기자 1순위가 **자동으로 정참가자로 승격** (채널에 안내 뜸)

---

## 📋 정리 버튼은 뭐?

정원이 다 찬 후, **모집 시작한 사람**이 누르면 → 티어 순으로 정리된 **참여자 명단**이 발송됩니다.

**예시 출력**
```
완댕이#명명펀치    M350    MID, TOP

정도#kr1          D1      MID, JG
다른분#kr2        D3      AD

랜덤분#test       E2      TOP
```

같은 티어끼리 묶이고, 다른 티어 사이엔 한 줄 띄어요.

---

## ❓ 자주 묻는 거

**Q. 참가하기 눌렀는데 안 돼요**
별명 형식이 안 맞아요. 본인에게만 보이는 안내 메시지를 읽고 별명 고친 다음 다시 누르세요.

**Q. 닉네임 바꾸면 자동 반영?**
네. 누가 참가/취소를 누를 때마다 명단이 새로 그려집니다.

**Q. 모집 끝내려면?**
별도 마감 기능 없어요. 그냥 무시하거나 새로 시작하면 됩니다.

## 📌 3줄 요약

1. 별명 `롤닉#태그/티어/라인` 으로 바꾸기 (한 번만)
2. 채널에 `/내전모집` → 사람들 🟢 참가하기
3. 정원 다 차면 시작한 사람이 📋 정리 누르기
